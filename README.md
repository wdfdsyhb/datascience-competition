# datascience-competition

数据竞赛全流程 **Agent 技能**（天池 / Kaggle / 电赛）：六阶段工作流 + 过拟合诊断 + 模型融合指南。

## 安装

把本仓库放进你的 AI 编码工具技能目录：

```
~/.zcode/skills/datascience-competition/     # ZCode
```

触发词：`打比赛` / `竞赛baseline` / `模型融合` / `提交策略`

## 内容

| 文件 | 作用 |
|---|---|
| `SKILL.md` | 技能入口 + 六阶段工作流 |
| `ensemble-guide.md` | 模型融合策略（加权/stacking/blending） |
| `overfit-checklist.md` | 过拟合诊断速查 |

## 六阶段工作流

赛道分析 → Baseline → 特征上探 → 模型融合 → 提交策略 → 复盘
