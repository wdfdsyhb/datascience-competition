# datascience-competition · Data Competition Agent Skill

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

> Install it into your AI coding tool as a competition skill: one phrase — "enter a competition" — triggers a six-stage workflow from track analysis to submission review, backed by two quick references on model ensembling and overfitting diagnostics.
>
> English: An AI-agent skill for data competitions — say "enter a competition" to trigger a six-stage workflow from track analysis to submission review, with ensemble and overfit-checklist guides.

## Installation

Drop this repository into your AI coding tool's skills directory:

```
~/.zcode/skills/datascience-competition/     # ZCode
```

Trigger words: `打比赛` ("enter a competition") / `竞赛baseline` ("competition baseline") / `模型融合` ("model ensembling") / `提交策略` ("submission strategy").

## Contents

| File | Purpose |
|---|---|
| `SKILL.md` | Skill entry point + six-stage workflow |
| `ensemble-guide.md` | Model ensembling strategies (weighted / stacking / blending) |
| `overfit-checklist.md` | Overfitting diagnostics quick reference |

## Six-Stage Workflow

Track analysis → Baseline → Feature exploration → Model ensembling → Submission strategy → Retrospective
